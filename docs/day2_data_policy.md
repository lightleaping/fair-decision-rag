# Day 2 — A 작업 결과: chunk 데이터 필드 및 정제 기준

## 1. Day 2 목표

공정거래 의결서 chunk 데이터에서 검색과 답변 생성에 필요한 핵심 필드와 법률 정보를 정의한다.

## 2. 필수 chunk 필드

본 프로젝트에서 하나의 chunk는 최소한 다음 필드를 가져야 한다.

| 필드 | 설명 |
|---|---|
| chunk_id | 검색 결과로 반환할 핵심 ID |
| document_id | chunk가 속한 의결서 ID |
| chunk_text | 검색과 답변 생성에 사용되는 원문 텍스트 |
| page | 원문 페이지 위치 |
| section_type | 주문, 이유, 별지 등 문서 구역 |
| metadata | 사건명, 기업명, 법 조항 등 추가 정보 |

## 3. 반드시 보존해야 하는 법률 정보

전처리 과정에서 다음 정보는 제거하지 않는다.

- 법 조항
- 기업명
- 날짜
- 금액
- 과징금
- 시정명령
- 고발
- 담합
- 하도급
- 부당한 공동행위
- 거래상지위남용
- 표시광고
- 가맹사업

## 4. 특히 중요한 정보

검색 정확도와 답변 근거 추적을 위해 다음 정보는 반드시 보존한다.

1. 법 조항
2. 기업명
3. 금액
4. 처분 내용

예를 들어 다음 표현은 삭제하거나 단순화하지 않는다.

- 제19조
- 제3항
- 2021. 5. 10.
- 1,000,000원
- 1억 원
- 주식회사 ○○
- 피심인
- 시정명령
- 과징금
- 고발
- 부당한 공동행위

## 5. 제거해도 되는 정보

검색 성능에 큰 도움이 되지 않는 다음 정보는 정리할 수 있다.

- 불필요한 연속 공백
- 반복 줄바꿈
- 페이지 머리말/꼬리말
- 문서 번호만 반복되는 문장
- 깨진 특수문자
- 의미 없는 구분선

예시:

```text
----------
=====
\n\n\n\n

권장 chunk 구조

  "document_id": "decision_0001",

    "company": "기업명",

  }
}
