# Day 5 — A 작업 결과: Dense Retrieval 기초 설계

## 1. Day 5 목표

의결서 chunk를 벡터로 변환할 임베딩 모델을 선택하고, Dense Retrieval의 역할과 검색 결과 확인 기준을 정리한다.

## 2. Dense Retrieval이 필요한 이유

BM25는 키워드가 정확히 일치할 때 강하지만, 사용자가 원문과 다른 표현으로 질문하면 관련 chunk를 놓칠 수 있다.

예를 들어 사용자가 다음과 같이 질문할 수 있다.

```text
기업들이 가격을 같이 정한 사례가 있나요?

하지만 원문에는 다음처럼 적혀 있을 수 있다.

피심인들은 판매가격을 공동으로 결정하기로 합의하였다.

또는 다음처럼 적혀 있을 수 있다.

이는 부당한 공동행위에 해당한다.

이 경우 Dense Retrieval은 표현이 다르더라도 의미가 유사한 chunk를 찾는 데 도움이 된다.
